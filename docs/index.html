OGG TTS

Expressive multilingual text-to-speech with block diffusion over Fish Audio codec tokens. Zero-shot voice cloning, optional emotion tags, context-aware delivery and streaming.

Preview: checkpoint 430k of a pre-training run that ended at 440k steps (evaluation below). The samples and the playground still use checkpoint 120k, which is steadier without a voice prompt. Built with Fish Audio.
Expressive by default

Reads with emotion that fits the text and its context, no tags needed.

24 inline tags

[angry] [whispering] [laughing] [sighing] … placed where they should take effect.

Zero-shot cloning

From a few seconds of reference audio and its transcript, or with the model's own voice.

Streaming

Blocks of 0.74 s are final once decoded and can be played immediately.

Architecture

A text-and-audio transformer (OmniVoice, initialised from Qwen3-0.6B) generates the semantic codebook of the Fish Audio codec block by block. An axial multi-token-prediction decoder fills in the 9 acoustic codebooks, and the codec renders 44.1 kHz audio.

ComponentDetails
BackboneOmniVoice / Qwen3-0.6B, 28 layers, d = 1024, block attention (Figure 2)
Acoustic decoderAxial MTP, 6 layers, d = 768, 110M parameters
Parameters~0.75B (codec excluded)
CodecFish Audio Drama 3 / S2: 44.1 kHz, 21.5 frames/s, 1 semantic codebook (4096) + 9 residual (1024)
Block16 frames = 0.74 s
Decoding6 unmasking iterations with classifier-free guidance, then 9 MTP steps, per block; KV cache
Trainingabout 8,200 h of studio-quality speech in 8 languages (a private collection), 1× RTX PRO 6000, 440k steps

Usage

git clone https://github.com/FashionFlora/ogg-tts && cd ogg-tts
git clone https://github.com/fishaudio/fish-speech ogg_tts/fish-speech
export OMNIVOICE_PATH=$(huggingface-cli download k2-fsa/OmniVoice)
export FISH_CODEC_PATH=$(huggingface-cli download fishaudio/drama-3 codec.pth)
import sys; sys.path.insert(0, "ogg_tts")
from huggingface_hub import hf_hub_download
import infer_omnifish as inf, fish_codec as fc

model, tok = inf.load_model(hf_hub_download("FashionFlora/ogg-tts", "model.safetensors"), "cuda")
codec = fc.load_codec("cuda")
codes = inf.generate_cached(model, tok, None, "", "[sighing] Hello! I am OGG.", "en", cfg=1.5)
audio = fc.decode(codec, codes[None].cuda())[0].float().cpu().numpy()   # 44.1 kHz

Voice cloning: pass the reference codes (fc.encode) and its exact transcript. Context: semantic_left=(…) and after=(…). Details in the model card.
